## 📡 API Reference

Complete API endpoint specifications, payloads, RBAC permissions matrix, and status codes are documented in:
👉 **[Backend API Reference Documentation](docs/backend/api-reference.md)**

* **Authentication & Session:** `POST /login`, `POST /setup-password`, `GET /me`, `POST /forgot-password`, `POST /verify-reset-code`, `POST /reset-password`, `POST /logout`
* **Employee Management:** `POST /employees`, `GET /employees`, `GET /employees/:id`, `PATCH /employees/:id`, `DELETE /employees/:id`
